# C# + React Demo

A small learning project that connects an ASP.NET Core Web API to a React and TypeScript frontend.

## Planned structure

```text
src/
  Demo.Api/          ASP.NET Core Web API
  Demo.Web/          React + TypeScript frontend
tests/
  Demo.Api.Tests/    Backend tests
docs/                 Architecture and project notes
.github/workflows/    Continuous integration workflows
```

## First milestone

Build, test, and deploy a minimal end-to-end application where the React frontend displays a message returned by the C# API.
